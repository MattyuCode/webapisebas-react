## Pasos para el deploy en Railway
```git
   npm run build


   npm install serve
```

* y Agregar esto package json
```json
 "start": "serve dist"
```

### Para levantar el proyecto

```bash
   npm install
```
#### despues ejecutar el siguiente comando

```bash
  npm run dev
```

### Para instalar YUP
```bash
   npm i yup 
   npm install @hookform/resolvers yup
```
